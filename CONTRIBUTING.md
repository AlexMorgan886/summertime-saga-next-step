# Contributing

Contributions are welcome when they improve the accuracy or usefulness of the project.

## Useful Contributions

- Report an incorrect guide recommendation.
- Suggest a missing situation category.
- Suggest an appropriate resource for an existing category.
- Improve documentation.
- Report bugs or unclear behavior.

## Before Submitting a Change

Please explain:

1. What should be changed.
2. Why the change is needed.
3. Which situation or resource it affects.

For changes to the decision data, include a clear example showing the expected result.

## Issues

Use GitHub Issues to report bugs, incorrect mappings, or suggestions.

Please do not include private save files or other personal information in an issue.
