# Code of Conduct

## Our Standard

We want this project to remain a useful and respectful place for everyone.

Contributors are expected to:

- Be respectful and constructive.
- Keep discussions focused on the project.
- Provide useful information when reporting problems.
- Accept reasonable feedback.
- Avoid personal attacks, harassment, or discriminatory behavior.

## Unacceptable Behavior

The following is not acceptable:

- Harassment or personal attacks.
- Discriminatory comments.
- Deliberate disruption of project discussions.
- Sharing private or sensitive information.
- Abusive or threatening behavior.

## Reporting

If you encounter unacceptable behavior, report it privately to the project maintainers rather than starting a public argument.

Project maintainers may remove content or restrict participation when necessary to keep the project constructive and useful.
