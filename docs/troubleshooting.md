# Troubleshooting

If the Next Step Tool recommends a guide that does not solve the problem, try the following.

## 1. Check the Recommendation

Read the recommended guide and compare its requirements with your current situation.

The tool provides a starting point rather than a guaranteed solution.

## 2. Try the Broader Walkthrough

If the issue is related to story progression, check the walkthrough and compare your completed events with the documented progression.

## 3. Check for a Technical Problem

If the issue involves:

- Saves
- Updates
- Installation
- Loading
- Compatibility

use the relevant troubleshooting or compatibility resource.

## 4. Check the Game Version

Different versions can have different progression behavior.

Check the version history when investigating a version-specific problem:

https://summersagahub.com/summertime-saga-version-history/

## 5. Report an Incorrect Recommendation

If the tool consistently recommends an unsuitable resource, open a GitHub issue and provide:

- The situation you entered
- The category returned
- Why the recommendation was unsuitable
- What resource you believe would be more appropriate

Do not upload private save files or personal information.

## Important

The tool does not read save files or determine the player's exact story state. Its purpose is to help narrow down which resource to check first.
